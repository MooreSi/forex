# HANDOFF — start here if you are picking up this work

You are picking up a **live-money MetaTrader 5 forex trading application** that is being refactored
and prepared to hand to its owner. Read this file first, then the rules it points to. It is the
single entry point for a new agent or developer.

---

## 0. The one rule that overrides everything

This app places **real orders on a real broker account with real money.** Before you change
anything, read — in order — **[CLAUDE.md](CLAUDE.md)** and
**[docs/system/rules/00-start-here.md](docs/system/rules/00-start-here.md)** →
**[10-golden-rules.md](docs/system/rules/10-golden-rules.md)**. They are short and not optional.

Never place/close/modify a real or demo order to test. Never edit a test to make a change pass.
Write the test first and watch it fail. `python -m tools.checks all` must be green before any commit.

## 2. Where questions go — put them in `docs/questions/`

If you hit a decision you cannot make from the code, the rules, or a sensible default — **do not
block, and do not guess a money/policy answer.** Pick a safe provisional default, proceed, and
**write the open decision as a file in [docs/questions/](docs/questions/)** (see its README for the
format). Simon reviews that queue and answers. A provisional default must keep trading no more
aggressive than today and is never silent — record what you chose and what changes if the answer
differs. Confirming a queue item is a *decision*; it is **not** the money-path sign-off + demo
session that order/close/sizing changes still require.

## 3. How to run it locally (debug mode — offline, no credentials)

Darren can now boot the whole app with no MT5, no Telegram, no network:

```powershell
$env:FOREX_DEBUG_MODE=1 ; python run.py
```

Then open **http://localhost:8890** and log in with **`debug`** / **`debug`**.

- A genuine per-machine licence is generated by `python -m tools.generate_debug_licence` (activation,
  not a bypass — `guard.enforce()` is untouched). Run it once if boot complains about a licence.
- Debug mode isolates the DB to `forex_trader_debug.db` and shows a login. The chart is empty and
  says "MT5 Disconnected" because the **fake price bridge is not wired yet** (a planned task).
- Expect `LoopMonitor` stall warnings — the engines are heavy at idle; not an error (a known issue).
- `python run.py` (no debug) is the real app and requires real credentials + a real licence.

## 7. How to work (the short version)

1. Read the rules (§0). Read the affected `docs/system/domains/` file.
2. For anything bigger than a one-line fix, work from a plan-pack task. For money-touching code, run
   `/safe-change` and stop for Simon's sign-off.
3. Test-first: write the failing test (with a negative control), watch it fail, then implement.
4. `python -m tools.checks all` green before every commit. Never lower a ratchet baseline or edit a
   test to pass.
5. Report what you actually did, including what you skipped.
